# أدويتي — تطبيق أندرويد

## طريقة الحصول على ملف التطبيق (APK) مجانًا عبر GitHub

1. أنشئ حسابًا مجانيًا على https://github.com/signup
2. اضغط علامة + في أعلى الصفحة ثم **New repository**. اكتب الاسم `adwiyati`، واختر Public أو Private، ثم **Create repository**.
3. في صفحة المستودع اضغط **uploading an existing file**، ثم اسحب **كل محتويات** هذا المجلد (بما فيها المجلد `.github`) وأفلتها في الصفحة، ثم اضغط **Commit changes**.
   - إذا لم يظهر المجلد `.github` بعد الرفع: اضغط Add file ثم Create new file، واكتب في خانة الاسم `.github/workflows/build.yml` والصق محتوى الملف `build.yml`.
4. افتح تبويب **Actions**، ثم افتح التشغيل (Build APK). انتظر 3 إلى 8 دقائق حتى تظهر علامة ✓ خضراء.
5. افتح التشغيل المنتهي، وفي أسفل الصفحة قسم **Artifacts** نزّل `adwiyati-apk`، ثم فك الضغط لتحصل على `app-debug.apk`.
6. انقل الملف إلى جوالك (واتساب لنفسك، أو بريد، أو كابل)، وافتحه، واسمح بالتثبيت من هذا المصدر. إذا ظهر تحذير Play Protect اختر **Install anyway**.

إذا ظهرت علامة ✗ حمراء: افتح التشغيل الفاشل، وانسخ آخر الأسطر الحمراء من السجل وأرسلها لي لأصلح المشكلة.

## ما الجديد في نسخة التطبيق
- الأوقات تحت كل دواء تفتح تطبيق **الساعة** مباشرة على شاشة منبه جاهزة (الوقت والاسم وأيام التكرار)، وزر **ضبط الكل** يضبط جميع منبهات الجرعات دفعة واحدة. المنبهات تعمل والتطبيق مغلق وبدون إنترنت.
- زر الإرسال يفتح قائمة المشاركة (واتساب وغيره) بصورة القائمة.
- الكاميرا والاستوديو بالطريقة العادية.

## ملاحظات
- بيانات التطبيق منفصلة عن بيانات المتصفح: الأدوية التي أدخلتها في المتصفح لا تنتقل تلقائيًا.
- قراءة الأسماء من الصورة تحتاج إنترنت أول مرة.
- هذا ملف تجريبي موقّع بمفتاح التطوير (debug)، وهو مناسب للاستخدام الشخصي.
